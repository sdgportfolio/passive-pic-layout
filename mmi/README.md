# 1×4 Multimode Interference Splitter

A parametric GDSFactory layout for a 1×4 multimode-interference coupler designed to divide the input optical power equally among four output waveguides.

## Planned Features

- Parameterized multimode-region dimensions
- Symmetric four-port output arrangement
- Input and output tapers
- Automated waveguide routing
- Optical ports for PIC integration
- GDSII export for KLayout
- Layout variants for parameter sweeps

## Status

Under development.

Equal-power splitting and insertion loss will be verified through electromagnetic simulation.
