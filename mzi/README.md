# Mach–Zehnder Interferometer Demultiplexer

A parametric GDSFactory layout for an asymmetric Mach–Zehnder interferometer designed to function as a wavelength demultiplexer for 1548 nm and 1550 nm.

The layout will include a 1×2 input splitter, two interferometer arms with a controlled path-length difference, and a 2×2 output combiner.

## Planned Features

- Parameterized waveguide dimensions
- Adjustable MZI arm-length difference
- Automated waveguide routing
- Optical input and output ports
- Path-length verification
- GDSII export for KLayout

## Status

Under development.

The target wavelength response will be verified through photonic-circuit simulation.
